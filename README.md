# 🏦 bankOfSpain: Nature-related Risk Assessment Pipeline

A research pipeline to explore companies Nature-related Risks. A case with the Bank of Spain.

> 🚧 **Under active development** 🚧<br>

## Notes

### 20250801

-   Trait dataframe completed for 13 mammal species. \*(Galemys pyrenaicus, a freshwater mammal, has been added to the general pipeline from the SRIT database.)\*

-   For homeRange values:

    -   Some species use genus-level averages.

    -   Others have species-specific values.

    -   Galemys pyrenaicus uses a value from the combined trait database.

## Repository Overview

This repository contains all scripts and supporting materials used in the modeling and analysis pipeline.<br>

| Folder | Description |
|:-------------|:---------------------------------------------------------|
| **data** | Raw data, including trait dataset for 13 mammal species, sourced from multiple databases. |
| **src** | All R scripts used in data analysis, modeling, and visualization |
