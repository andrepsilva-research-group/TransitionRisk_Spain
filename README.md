# 🏦 bankOfSpain

[![DOI](https://img.shields.io/badge/DOI-coming_soon-blue?logo=doi&logoColor=white)](https://doi.org/10.0000/placeholder)

A research pipeline to explore companies Nature-related Risks. A case with the Bank of Spain.

> 🚧 **Under active development** 🚧<br>


## Repository Overview

This repository contains all scripts and supporting materials used in the modeling and analysis pipeline.<br>

| Folder | Description |
|:-------------|:---------------------------------------------------------|
| **data** | Raw data, including trait dataset for 13 mammal species, sourced from multiple databases. |
| **src** | All R scripts used in data analysis, modeling, and visualization. >br> ➡️ For full details, see the [`src/README.md`](src/README.md)<br><ul><li>SDM input data preparation</li><li>SDM building</li><li>output visualization</li></ul> |
